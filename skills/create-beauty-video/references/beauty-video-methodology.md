# 美妆视频方法论

## 两层分析

先做机器可复核的技术扫描，再做语义拆解。技术扫描记录时长、帧率、画幅、
音频、关键帧和候选切点；语义拆解只对代表帧作判断，并把不确定的判断标成
inferred，不能伪装成用户提供的事实。

建议每个候选镜头至少记录：

- shotId、startSec、endSec、durationSec
- 景别、机位、镜头运动、主体状态、动作和转场
- 可见的产品包装面、文字、颜色、材质和相对比例
- 人物脸部状态、妆容阶段、发型、服装和手部可见性
- 场景、背景、光线方向、色温、阴影和风格
- 需要的输入资产、首帧状态和视频动作

analyze_reference_video.py 只负责技术数据和取样帧。Codex 负责查看帧、
理解动作，并修正切点。没有视觉证据的字段写 unknown，不要从美妆常识
补全人物或产品。

## 连续性圣经

把跨镜头必须稳定的事实分成四类：

1. 人物锚点：只写已确认的脸型、肤色、发型、妆容阶段和可见服装。
2. 产品锚点：品牌标识、包装形状、瓶盖、主色、材质、文字方向和比例。
3. 场景锚点：背景、台面、光源方向、色温、景深和画面比例。
4. 风格锚点：摄影质感、颗粒、对比度、色彩、节奏和平台安全边界。

每一项带 source（用户资产、参考帧、用户确认或推断）和 confidence。
推断项必须在提交前让用户确认。资产角色不写死，角色只是指向文件夹和
镜头依赖的标签；已有系统文件夹优先复用。

## 首帧优先

首帧承担身份和视觉状态锁定：

- 图片提示词描述人物、产品、场景、构图、光线和静止姿态；
- 每个片段只锁定一张首帧，候选图要与连续性圣经逐项比对；
- 产品需要新角度时，先生成产品角度参考图，再编译首帧；
- 视频提示词只描述从首帧开始的动作、镜头运动、时序和结束状态；
- 不在视频提示词里重新发明脸、包装、背景或风格。

只有当锁定首帧无法表达输入要求时，才把多参考图作为显式的模型策略，
并记录每个参考图的用途和失败风险，不能因为模型支持就自动附加全部素材。

## 印尼 TikTok 真人感 profile

新印尼 TikTok 美妆 UGC 计划使用 id_tiktok_beauty_ugc_real_person_v1。它
不是人物国籍模板，而是把可观察事实写进镜头提示词的编译顺序：

画面事实 -> t=0 起始状态 -> 唯一主动作 -> 视线/微表情因果链
-> 手机镜头/光线/环境 -> 声音 -> 少量护栏

- 默认脸部特写、头肩近景或产品与局部面部同框，不生成全身三视图。
- 身份锚点只来自已批准参考图：脸型体积、下颌转折、眼型和自然不对称、
  肤色过渡、发型/头部包裹、服装颜色等实际可见事实。
- 保留毛孔、鼻翼/面颊自然光泽和轻微肤色层次；不要自动写无瑕、玻璃肌、
  瓷娃娃、大眼、尖下巴或商业棚拍。
- 首帧是动作前的自然基线：闭嘴或预说话状态、肩膀放松、正常呼吸、明确
  视线和头部角度。它不能提前出现最终妆效或动作中间状态。
- 每段只允许一个主动作，动作窗口要落在真实 PTS 或已确认自然时长内。
  眨眼、呼吸和微小头动只作为辅助变化。
- 视频必须写出自然基线 -> 外部触发 -> 可见反应 -> 轻微恢复；不要全程
  固定笑容、持续瞪眼或无因果游移视线。
- 9:16 手机 UGC 使用明确主光方向、脸部受光、白平衡、曝光和真实生活背景，
  只允许轻微自动曝光/对焦呼吸，不能改变光线方向或肤色。
- 产品可见时绑定同角度、同开合、同透视的产品资产，并明确主手、握持点、
  运动路径和停留位置；包装小字后期处理。

## 动作预算

动作数量、拆片阈值和镜头响应必须由当前用户确认的规则 profile 决定。未选择
已批准 profile 时，Codex 只能记录动作候选、风险和待确认项，不能把一到三个
动作写成通用执行规则。每个动作仍应记录主体、方向、速度、起止时间和镜头
响应。显式选择印尼真人 profile 时，使用该 profile 的单一主动作约束。

## 质量门

生成候选后按以下顺序检查：

1. 身份：人物面部、妆容阶段和产品包装是否与锚点一致；
2. 构图：首帧是否能自然承接上一片段和目标画幅；
3. 动作：视频提示词是否符合已选规则 profile 和确认的动作预算；
4. 文字/商标：是否出现未确认或变形的文字；
5. 记录：资产、模型、费用、节点和导出是否有可追溯 ID。

任一质量门失败时，回到对应的首帧或资产阶段，不用追加更多视频动作来
掩盖问题。
