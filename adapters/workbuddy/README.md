# WorkBuddy adapter (Verification)

WorkBuddy has no verified native Skill installation contract in this release.
Use the Portable Markdown/OpenAPI/CLI adapter and keep the status as
`Verification` until WorkBuddy configuration loading and the full auth →
Preview → Run → result sequence are verified.

Use `clientType=workbuddy` for device authorization. Preview is always a
no-generation, no-credit operation and requires explicit user approval before
Compile/Run.
